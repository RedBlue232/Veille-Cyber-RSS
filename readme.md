# Veille Cyber · CTI · DFIR

Une sélection de flux RSS pour la veille en cybersécurité : threat intelligence, DFIR, détection & réponse, vulnérabilités et CERT.

Publiée dans l'esprit de [l'article de l'EFF sur le RSS](https://www.eff.org/deeplinks/2026/06/hate-algorithm-rss-one-tools-youve-been-looking) : reprendre la main sur ses sources d'information, sans algorithme ni intermédiaire.

## Utilisation

Importez [`veille-cyber.opml`](./veille-cyber.opml) dans n'importe quel lecteur RSS (CommaFeed, FreshRSS, Miniflux, Thunderbird, Feedly…) via l'option **Import OPML**.
